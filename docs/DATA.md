# Local data layout

These paths are **gitignored**. Copy your own files after clone:

| Path | Purpose |
|------|---------|
| `data/products_export.csv` | Shopify product export for `npm run db:import` |
| `data/scraped-data/` | Optional scrape (`website-data.json` + `assets/images/`) for handle→image matching |
| `public/products/` | Generated by import — served at `/products/{slug}/...` |

## Setup order

```bash
npm run db:sync
```

Or step by step (import **before** seed so the hero banner and reviews use real products):

```bash
npm run db:push
npm run db:import    # products + images
npm run db:seed      # users, coupons, banner, approved homepage reviews
```

Re-run `db:import` after updating the CSV or scrape folder.
